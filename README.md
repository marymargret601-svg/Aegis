# Aegis - Real-Time AI Financial Risk Manager

Aegis is an AI-driven, pre-execution financial security engine designed for real-time fraud prevention on checkout rails. Built for **Razorpay Buildathon (Track 02: AI Risk Manager)**, Aegis evaluates transaction telemetry in real-time *before* payment execution, balancing security and user experience through dynamic 2FA step-up challenges.

---

## 🛠️ Architecture & Tech Stack

* **Backend**: Python 3.10+, FastAPI, Uvicorn, Pydantic
* **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3, Chart.js
* **Security & Logic**: Weighted heuristic risk engine, Explainable AI (XAI) signal matrix, dynamic 2FA modal interception
